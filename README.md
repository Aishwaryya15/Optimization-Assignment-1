# Optimization Techniques Assignment 1

This repository contains the Python programs for Optimization Techniques Assignment 1.

## Methods Used

1. Big-M Method
2. Vogel's Approximation Method (VAM)
3. Modified Distribution Method (MODI)

## Files

- `big_m.py` - Solves an LPP using the Big-M method.
- `vam.py` - Finds an initial feasible solution using Vogel's Approximation Method.
- `modi.py` - Checks and obtains the optimal transportation cost using the MODI method.

## Results

- Big-M Method: Maximum Z = 18
- VAM: Initial Transportation Cost = 1400
- MODI: Minimum Transportation Cost = 1400
