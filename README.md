# Optimization Techniques Assignment 1

This repository contains the Python programs for CS2105 Optimization Techniques Programming Assignment.

## Methods Used

1. Big-M Simplex Method
2. Vogel's Approximation Method (VAM)
3. Modified Distribution Method (MODI)

## Files

- `big_m.py` - Solves the given constrained LPP using the Big-M method.
- `vam.py` - Finds the initial feasible transportation solution using VAM.
- `modi.py` - Obtains the optimal transportation solution using MODI.

## Results
